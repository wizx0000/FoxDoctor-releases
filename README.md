# Fox Doctor／Fox Care 發行檔

這裡只放 Fox Doctor 與 Fox Care 的發行檔（Windows 10／11 64 位元）。

## 下載

到右邊的 **Releases** 下載最新版的 `FoxDoctor-版本-win-x64.zip`，解壓縮後執行 `FoxDoctor.exe` 或 `FoxCare.exe`，不需要安裝。

- **Fox Doctor**：只讀不改，查看硬體狀態、規格、網路診斷、事件紀錄。
- **Fox Care**：軟體更新、磁碟清理、執行元件等，每次動手前都會先詢問。

每個 ZIP 旁邊的 `.sha256` 是檔案指紋，用來確認下載的檔案完整、沒被修改。

## 更新

1.1.0 起，Fox Doctor 開啟時會自動檢查這裡有沒有新版，有的話會詢問是否更新。
